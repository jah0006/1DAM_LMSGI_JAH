HTML5 ha llegado para quedarse

HTML5 es la ultima version de HTML. El término representa dos conecptos diferentes: Se trata de una nueva version de HTML, con nuevos elementos, atributos y comportamientos. Contiene un conjunto más amplio de tecnologías que permite a los sitios web y a las aplicaciones ser más diversas y de gran alcance. A este conjunto se le llama HTML5.

CSS3, la nueva version de CSS

CSS significa Cascade style Sheets, también llamado Hojas de Estilo en Cascada. CSS es un lenguajes de marcado que se emplea para dar formato a un siito web. Es decir, funciona en conjunto con los archivos HMTL. Por esta razón, para hacer un sitio web, debes saber tanto HTML como CSS
